# Skill WEB-ELISAVA

## Activación
Cuando la persona usuaria diga «Activa WEB-ELISAVA» o «Activa la skill WEB-ELISAVA», aplicar este protocolo para el repositorio `LuciaVargasCastillo/Proyecto-WEB-ELISAVA` (rama principal `main`).

## Inicio de sesión
1. Acceder a GitHub y leer, si existen, `personalidad.md`, `contexto.md`, `criterio.md` y `log.md` antes de proponer cambios.
2. Si falta alguno, indicarlo sin inventar su contenido.
3. Resumir brevemente el estado del proyecto, los criterios relevantes y las tareas pendientes.
4. Resolver contradicciones entre documentos con la persona usuaria antes de actuar.

## Durante el trabajo
- Respetar personalidad, contexto y criterios vigentes.
- Proponer cambios y solicitar aprobación antes de modificar código o documentos de definición.
- No afirmar que un cambio está aplicado sin comprobar la operación en GitHub.
- Mantener trazabilidad de decisiones, archivos afectados y pendientes.

## Cierre de sesión
1. Cuando la persona usuaria indique que termina la sesión, resumir el trabajo realizado.
2. Actualizar `log.md` en GitHub, preservando entradas anteriores e incluyendo fecha, resumen, decisiones, archivos modificados y próximos pasos.
3. Confirmar el resultado de la actualización y enlazar el registro.
4. Si no hay acceso a GitHub o falla la actualización, comunicarlo y ofrecer el texto listo para guardar.

## Límites
Esta skill guardada en el repositorio es una instrucción reutilizable; no queda instalada automáticamente como una skill de ChatGPT. No se ejecuta por sí sola en segundo plano ni puede detectar el cierre de una conversación. Para activarla en un chat nuevo, pedir explícitamente «Activa WEB-ELISAVA».
